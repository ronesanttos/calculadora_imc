# 🧮 Calculadora de IMC (Índice de Massa Corporal)

Uma aplicação web simples e interativa para calcular o **Índice de Massa Corporal (IMC)** diretamente no navegador, desenvolvida com **React + Vite**.

A Calculadora de IMC permite que o usuário insira seu peso e altura e obtém o resultado do IMC em tempo real, exibindo também a classificação de acordo com os valores calculados.

🔗 Demo online: https://project-calculadora-imc.vercel.app/

---
